## What each diagnostic establishes

The HLS comparison observed the actual master/main responses for ASS/MKV and SRT/MP4 at 41 seconds using the reviewed baseline profile. Both declare VOD, sequence zero, segments 0-20, twenty-one `EXTINF:3.0000` values, 63 seconds total, ENDLIST, and `EXT-X-START:TIME-OFFSET=41`. Their source durations are 60.033 and 60.010646 seconds and their master frame rates differ at 30.083 and 30.000. It fetched zero media segments and completed each own StopEncoding/logout with 204. It cannot prove that the declared final segment is available.

The tail replay preserved the two actual historical command parameter sets and changed only output paths. The successful MP4/SRT producer starts at 39 seconds/segment 13; its final segment 20 has 2256 bytes, two H.264 packets, and three AAC packets. The failed ASS/MKV tail restart starts at 60 seconds/segment 20; its final TS has 3948 bytes, one H.264 keyframe, and six AAC packets. Both FFmpeg and FFprobe exited zero. This rejects absent output/audio and a nonzero FFmpeg exit as descriptions of that reproduced tail command. It does not reveal the exact internal Emby initialization rejection or form a single-variable media experiment. The collector's `ServerInputsUnchanged` flag records output-only argument rewriting; the receipt includes input hashes but not a separate before/after checksum measurement.

The progressive control uses the original ASS source, changes only the copied transcoding profile container/protocol to HTTP/MP4, and preserves request flags corresponding to `ForceTranscoding=false`. At zero and 41 seconds it requests bytes 0-65535 and reads exactly 65536 bytes from each `200` chunked response. The server supplies no Content-Length or Content-Range and advertises `Accept-Ranges: none`. Each prefix contains complete top-level `ftyp`, `moov`, and `moof` boxes; the bounded reads do not verify the complete media stream. Both response connections were disposed and both own StopEncoding/logout pairs returned 204. No Playing report, native graph, screenshot, seek, subtitle-disable transition, or resource observation occurred.
